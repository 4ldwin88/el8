# Intelligence E2E QA contract

This surface is a QA adapter over canonical EL8 Intelligence. It must not become a parallel Intelligence implementation.

Canonical journey: Discovery opening evidence → adaptive Discovery → completed Discovery evidence → initial Member State baseline snapshot → Prioritization → Planning → activation/intervention → outcome/review → learning/adaptation → reassessment.

Rules:
- Baseline is not a stage, questionnaire, or input to Discovery. It is the initial Member State snapshot established from completed Discovery evidence.
- Tester pages import production/canonical subsystem adapters wherever browser-safe adapters exist.
- Discovery does not construct plans. Prioritization and Planning retain their own authority.
- Safety, uncertainty, evidence references, member capacity, and decision trace must survive subsystem boundaries.
- Accelerated QA may compress time but must use the same review/adaptation logic as the canonical loop.
- Legacy E2E pages are migration evidence only. Remove them when their unique QA behavior is represented by the canonical journey.
