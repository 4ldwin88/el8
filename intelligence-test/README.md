# Intelligence E2E

Canonical QA surface for Intelligence v0.1.

The test begins inside Discovery. The opening snapshot is evidence collection within Discovery, not a Baseline assessment. Completed Discovery establishes the member's initial baseline as part of canonical Member State. Downstream QA must then exercise canonical Prioritization, Planning, activation/intervention, outcome review, learning/adaptation, and reassessment.

Do not add component-specific version labels or duplicate domain logic in this folder. Pages are presentation/test adapters over canonical modules.
